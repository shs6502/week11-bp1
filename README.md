# 살롱 드 루미에르

바로크의 우아한 분위기와 커피의 따뜻함을 담은 카페 홈페이지입니다. HTML 한 파일로 구성되어 있으며 CSS와 JavaScript도 `index.html` 안에 포함되어 있습니다.

## 실행 방법

`index.html`을 브라우저에서 열면 별도의 설치나 빌드 과정 없이 확인할 수 있습니다.

## 주요 기능

- 바로크 분위기를 살린 카페 소개 및 반응형 레이아웃
- 커피, 디저트, 티 메뉴 8종과 카테고리별 필터
- 메뉴의 주문 담기 버튼 및 알림
- 다크 모드와 라이트 모드 전환
- 모바일 내비게이션 메뉴
- 매장 정보와 운영자 연락처 표시

## 파일 구성

- `index.html`: 페이지 구조, 스타일, 인터랙션을 포함한 홈페이지
- `README.md`: 프로젝트 소개 및 사용 안내

폰트와 메뉴 사진은 외부 웹 서비스에서 불러오므로 해당 리소스를 표시하려면 인터넷 연결이 필요합니다.
